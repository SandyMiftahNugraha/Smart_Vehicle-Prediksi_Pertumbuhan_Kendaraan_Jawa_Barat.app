# 🚗 Prediksi Pertumbuhan Kendaraan Jawa Barat

Dashboard interaktif berbasis Streamlit untuk analisis dan prediksi pertumbuhan kendaraan bermotor di Provinsi Jawa Barat menggunakan Machine Learning.

## 📖 Deskripsi Proyek

Proyek ini bertujuan untuk menganalisis tren pertumbuhan kendaraan bermotor di Kabupaten/Kota Provinsi Jawa Barat berdasarkan data historis tahun 2016–2025. Selain visualisasi data, aplikasi ini juga menyediakan fitur prediksi untuk membantu memahami pola pertumbuhan kendaraan di masa mendatang.

## 🎯 Tujuan

- Menganalisis perkembangan jumlah kendaraan bermotor di Jawa Barat.
- Menampilkan visualisasi data yang interaktif dan mudah dipahami.
- Membangun model Machine Learning untuk memprediksi pertumbuhan kendaraan.
- Mendukung pengambilan keputusan berbasis data pada sektor transportasi dan Smart City.

## ✨ Fitur Utama

- Login pengguna
- Dashboard interaktif
- Visualisasi data kendaraan bermotor
- Analisis tren pertumbuhan kendaraan
- Prediksi jumlah kendaraan menggunakan Machine Learning
- Statistik dan insight data
- Tampilan responsif berbasis Streamlit
