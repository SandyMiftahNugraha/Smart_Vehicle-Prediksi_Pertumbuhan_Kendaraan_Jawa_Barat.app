# Prediksi Pertumbuhan Kendaraan Jawa Barat

Aplikasi Streamlit untuk menganalisis dan memprediksi pertumbuhan kendaraan bermotor di Jawa Barat menggunakan data Open Data Jabar dan BPS.

## Fitur
- Visualisasi data kendaraan
- Analisis tren pertumbuhan
- Prediksi menggunakan Machine Learning
- Dashboard interaktif

## Teknologi
- Python
- Streamlit
- Pandas
- Scikit-Learn
- Matplotlib
- Plotly

## Cara Menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py
